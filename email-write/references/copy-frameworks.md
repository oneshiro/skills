# Copy Frameworks

Use these frameworks only for conversion-focused email. Prefer the simplest
framework that fits the purpose.

## Selection

| Purpose | Framework | Emphasis |
| --- | --- | --- |
| Cold outreach or re-engagement | PAS | Recognized problem and credible relief |
| Product launch or promotion | AIDA | Attention through action |
| Welcome email or transformation story | BAB | Before and after state |
| Feature announcement | FAB | Feature translated into user value |
| Case study or proof-led offer | 4Ps | Promise supported by proof |
| Reminder or transactional message | Direct | Facts and next action |

Default to AIDA for marketing campaigns and PAS for relationship-led outreach
when no stronger fit exists.

## Structures

### PAS

1. **Problem:** Name a specific, relevant pain point.
2. **Agitate:** Explain its consequence without exaggeration.
3. **Solve:** Present the offer as a credible next step.

### AIDA

1. **Attention:** Lead with a relevant hook.
2. **Interest:** Connect the message to the recipient's context.
3. **Desire:** Show a supported benefit or outcome.
4. **Action:** Ask for one clear next step.

### BAB

1. **Before:** Describe the current state.
2. **After:** Show a realistic improved state.
3. **Bridge:** Explain how the offer helps reach it.

### FAB

1. **Feature:** State what exists.
2. **Advantage:** Explain what it enables.
3. **Benefit:** Connect it to a recipient outcome.

### 4Ps

1. **Promise:** State the relevant outcome.
2. **Picture:** Make the result concrete.
3. **Proof:** Support it with supplied evidence.
4. **Push:** Give a low-friction CTA.

## Subject Lines

Create three distinct options:

- **Curiosity:** Open a relevant information gap without clickbait.
- **Benefit:** State the clearest supported value.
- **Urgency:** Mention real timing or scarcity only when supplied.

Aim for 6-10 words and roughly 30-50 characters when the language permits.
Never use all caps. Use no more than one exclamation mark. Reject fabricated
personalization and spam-like phrases.

Score each option from 0-100 using:

| Criterion | Weight |
| --- | ---: |
| Clear topic or benefit | 30 |
| Specificity and relevance | 25 |
| Natural length | 20 |
| Appropriate curiosity or motivation | 15 |
| Tone and deliverability | 10 |

Subtract up to 50 for spam triggers, misleading urgency, or unsupported claims.
At least one subject must score 70 or higher; otherwise rewrite the set.

## Preheader

Write 30-80 characters when practical. Complement rather than repeat the
subject. Preview a secondary benefit, useful detail, or CTA.

## HTML

Generate HTML only when requested. Use a table-based layout, maximum width of
600px, web-safe fonts, inline critical styles, meaningful image alt text,
high-contrast CTA, mobile-readable type, and dark-mode metadata/styles. Include
a plain-text fallback. Avoid CSS Grid and Flexbox because email client support
varies.
